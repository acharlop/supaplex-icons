# Supaplex SVG

Every Supaplex sprite, font and screen as SVG. **Goal: pixel-exact match of the original up to 256px.** Above 256px corners soften slightly. A hand-drawn **smooth** version exists for some sprites; opt-in only.

**Live:** https://acharlop.github.io/supaplex-icons/

Status: all 103 entries pixel-exact up to 256px: 40 tiles, 53 animations, 2 fonts, 8 screens (541 SVGs). Smooth art for tiles only.

**Fonts:** `supaplex-6` and `supaplex-8` as [WOFF2 and TrueType](fonts/), [demo](https://acharlop.github.io/supaplex-icons/fonts.html). Capitals, digits, punctuation; lowercase types as capitals. Exact at font sizes 8, 16, 32… px. On macOS add `-webkit-font-smoothing: antialiased`, or edges blur.

```css
@font-face { font-family: 'Supaplex 8'; src: url(supaplex-8.woff2) format('woff2'), url(supaplex-8.ttf) format('truetype'); }
.hud { font: 16px/16px 'Supaplex 8'; -webkit-font-smoothing: antialiased; }
```

```sh
npm run dev      # build + serve on http://localhost:4173
npm run verify   # prove pixel SVGs match the original up to exactUpTo (needs Chrome + ffmpeg)
```

Settings at the top of `sprites.json`:

- `exactUpTo`: pixel-identical to the original up to this many px wide (default 256).
- `cornerCut`: how much corners round above that, in original pixels (default 0.25; `0` = never round).
- `smooth`: above `exactUpTo`, swap to the hand-drawn smooth art where a sprite has one. Default `false`; keep it off — the exact pixel output is the point.

## Layout

- `sprites.json`: the list. One entry per sprite, animation, font or screen, with its source file and frame coordinates. `"svg": true` marks entries in scope for SVG output; `todo` marks entries not yet mapped.
- `svg/pixel/`: generated by the build. One frame is `<id>.svg`; animations are `<id>/<n>.svg`; font glyphs are `font-N/<ascii hex>.svg` (`41.svg` = A). Tiles and animations make edge-touching black transparent, fonts make every unset bit transparent, screens keep all pixels and are exact at native 320px. An in-SVG media query trims convex pixel corners by `pixel.cornerCut` only when rendered wider than `pixel.exactUpTo` (both in `sprites.json`); `cornerCut: 0` emits the plain grid. With `pixel.smooth: true`, sprites that have `svg/smooth/<id>.svg` embed it instead and swap to it above `exactUpTo`. Committed; CI fails if the build changes them.
- `fonts/`: generated by the build from the font glyphs (`scripts/ttf.mjs`, no dependencies): one font pixel is 128 units, em is 8 pixels (7 ascent, 1 descent), advance is the glyph width. Outlines are traced pixel boundaries. WOFF2 stores the TrueType tables untransformed (glyf/loca null transform), Brotli in font mode. Committed; CI fails if the build changes them.
- `svg/smooth/`: hand-authored. Source of truth; never generated.
- `scripts/`: build pipeline. `assets.mjs` fetches the original `.DAT` files into `.cache/` and checks sha256; `dat.mjs` decodes the planar 4bpp bitmaps and palette; `svg.mjs` writes SVGs; `sprites.mjs` loads `sprites.json` and decodes each entry's frames, palette and output paths; `build.mjs` writes `svg/pixel/`, `fonts/` and `dist/`; `ttf.mjs` writes the font files. `verify.mjs` pixel-diffs every frame, and every glyph of each WOFF2 and TrueType file rendered as text, against the original at every power-of-two scale up to `exactUpTo`, shelf-packing renders onto a few headless Chrome screenshots (`CHROME` env overrides the binary path); `grid.mjs` prints a sprite's original frame as hex palette indices.
- `site/`: static, dependency-free viewer deployed to GitHub Pages by `.github/workflows/pages.yml`.

## Sources

Original game data is fetched at build time from [OpenSupaplex](https://github.com/sergiou87/open-supaplex) at a pinned commit, never committed here. Format details (planar layout, palette encoding) learned from OpenSupaplex; decoder written from scratch.

# Supaplex SVG

Every Supaplex sprite, font and screen as SVG. **Goal: pixel-exact match of the original up to 256px.** Above 256px corners soften slightly. A hand-drawn **smooth** version exists for some sprites; opt-in only.

**Live:** https://acharlop.github.io/supaplex-icons/

Status: all 103 entries pixel-exact up to 256px: 40 tiles, 53 animations, 2 fonts, 8 screens (541 SVGs). Smooth art for tiles only. 5 screens editable as HTML, plus 10 colour fonts learned from them.

**Screens:** [credits, menu, controls, cast, game panel](https://acharlop.github.io/supaplex-icons/screens/title-2.html) as HTML over an SVG background. Click text to edit it, drag icons, add or delete icons, fill the empty boxes, download the result. Credits plays the intro split from the first title screen. The [menu](https://acharlop.github.io/supaplex-icons/screens/menu.html) plays: every button works as in the game, over a save game a few weeks in, and OK starts the level in the game panel. Exact at 1x, 2x, 4x.

**Fonts:** `supaplex-6` and `supaplex-8` as [WOFF2 and TrueType](fonts/), [demo](https://acharlop.github.io/supaplex-icons/fonts.html). Capitals, digits, punctuation; lowercase types as capitals. Exact at font sizes 8, 16, 32… px. On macOS add `-webkit-font-smoothing: antialiased`, or edges blur.

```css
@font-face { font-family: 'Supaplex 8'; src: url(supaplex-8.woff2) format('woff2'), url(supaplex-8.ttf) format('truetype'); }
.hud { font: 16px/16px 'Supaplex 8'; -webkit-font-smoothing: antialiased; }
```

```sh
npm run dev      # build + serve on http://localhost:4173
npm run verify   # prove pixel SVGs match the original up to exactUpTo (needs Chrome + ffmpeg)
```

Settings at the top of `sprites.json`:

- `exactUpTo`: pixel-identical to the original up to this many px wide (default 256).
- `cornerCut`: how much corners round above that, in original pixels (default 0.25; `0` = never round).
- `smooth`: above `exactUpTo`, swap to the hand-drawn smooth art where a sprite has one. Default `false`; keep it off — the exact pixel output is the point.

## Layout

- `sprites.json`: the list. One entry per sprite, animation, font or screen, with its source file and frame coordinates. `"svg": true` marks entries in scope for SVG output.
- `svg/pixel/`: generated by the build. One frame is `<id>.svg`; animations are `<id>/<n>.svg`; font glyphs are `font-N/<ascii hex>.svg` (`41.svg` = A). Tiles and animations make edge-touching black transparent, fonts make every unset bit transparent, screens keep all pixels and are exact at native 320px. An in-SVG media query trims convex pixel corners by `pixel.cornerCut` only when rendered wider than `pixel.exactUpTo` (both in `sprites.json`); `cornerCut: 0` emits the plain grid. With `pixel.smooth: true`, sprites that have `svg/smooth/<id>.svg` embed it instead and swap to it above `exactUpTo`. Committed; CI fails if the build changes them.
- `fonts/`: generated by the build from the font glyphs (`scripts/ttf.mjs`, no dependencies): one font pixel is 128 units, em is 8 pixels (7 ascent, 1 descent), advance is the glyph width. Outlines are traced pixel boundaries. WOFF2 stores the TrueType tables untransformed (glyf/loca null transform), Brotli in font mode. Committed; CI fails if the build changes them.
- `screens.json`: the editable screens. `fonts` are learned from text `runs` (screen, position, string, `cuts` where letters touch): `ink` is the letter colours, `deco` the shadow colours with their offsets. `screens` lists each page's text runs, empty `slots` in the game fonts, and `icons` (a sprite frame, or a `crop` of the screen where no sprite matches). `script` loads `site/<script>.js` on the page; a `menu` script marks the screen `data-play`, which hides the editing tools.
- `screens/`: generated by `scripts/screens.mjs`. Per screen an `.html` page and an `.svg` background with every text and icon pixel inpainted; icon crops; for credits, `title-1.svg` and `title-2-dim.svg` (credits in the title-1 palette) for the intro. Learned fonts go to `fonts/supaplex-<name>.{ttf,woff2}`: COLRv0 layers per palette colour, legacy kern pairs, variants for letters drawn differently per occurrence on U+FE00+n, U+200A as a 1px space. `scripts/glyphs.mjs` does the learning and checks every run recomposes exactly. Pages take `?zoom=k`, `?bare` (black, no UI) and, on credits, `?at=end|0..121` (split offset). `verify` renders each page at 1x, 2x, 4x (sequentially; parallel Chrome hangs) and the intro at offsets 0, 60, 121 and end. Committed; CI fails if the build changes them.
- `svg/smooth/`: hand-authored. Source of truth; never generated.
- `scripts/`: build pipeline. `assets.mjs` fetches the original `.DAT` files into `.cache/` and checks sha256; `dat.mjs` decodes the planar 4bpp bitmaps and palette; `svg.mjs` writes SVGs; `sprites.mjs` loads `sprites.json` and decodes each entry's frames, palette and output paths; `build.mjs` writes `svg/pixel/`, `fonts/`, `screens/` and `dist/`; `ttf.mjs` writes the font files. `verify.mjs` pixel-diffs every frame, and every glyph of each WOFF2 and TrueType file rendered as text, against the original at every power-of-two scale up to `exactUpTo`, shelf-packing renders onto a few headless Chrome screenshots (`CHROME` env overrides the binary path); `grid.mjs` prints a sprite's original frame as hex palette indices.
- `site/`: static, dependency-free site deployed to GitHub Pages by `.github/workflows/pages.yml`. `index.html` + `home.js` is the landing page, `sprites.html` + `sprites.js` the catalogue, `fonts.html` the font demo. `supaplex.js` models the main menu as OpenSupaplex draws it (button hit boxes, pressed borders, ranking, level colours, info screens, the game panel); `menu.js` and `panel.js` drive it on the menu and panel pages, and `verify.mjs` checks its frames against the original. Level names and infotron counts come from `LEVELS.DAT` (`dat.mjs` `readLevels`). The menu saves to `localStorage`, or `sessionStorage` under `?bare`.

## Sources

Original game data is fetched at build time from [OpenSupaplex](https://github.com/sergiou87/open-supaplex) at a pinned commit, never committed here. Format details (planar layout, palette encoding) learned from OpenSupaplex; decoder written from scratch.

# Supaplex SVG

Every Supaplex sprite, font and screen, redrawn as SVG. Two versions each: **pixel** (exact original up to 128px, corners softened above) and **smooth** (hand-drawn vector).

**Live:** https://acharlop.github.io/supaplex-icons/

Status: setup done, Murphy done. Rest listed in [`sprites.json`](sprites.json) and on the site.

```sh
npm run dev   # build + serve on http://localhost:4173
```

Pixel softening is set at the top of `sprites.json`:

- `exactUpTo`: pixel-identical to the original up to this many px wide (default 128).
- `cornerCut`: how much corners round above that, in original pixels (default 0.25; `0` = never round).

## Layout

- `sprites.json`: the list. One entry per sprite, animation, font or screen, with its source file and frame coordinates. `"svg": true` marks entries in scope for SVG output; `todo` marks entries not yet mapped.
- `svg/pixel/`: generated by the build: the exact 16x16 grid, edge-touching black made transparent. An in-SVG media query trims convex pixel corners by `pixel.cornerCut` only when rendered wider than `pixel.exactUpTo` (both in `sprites.json`); `cornerCut: 0` emits the plain grid. Committed; CI fails if the build changes them.
- `svg/smooth/`: hand-authored. Source of truth; never generated.
- `scripts/`: build pipeline. `assets.mjs` fetches the original `.DAT` files into `.cache/` and checks sha256; `dat.mjs` decodes the planar 4bpp bitmaps and palette; `svg.mjs` writes SVGs; `build.mjs` writes `dist/`.
- `site/`: static, dependency-free viewer deployed to GitHub Pages by `.github/workflows/pages.yml`.

## Sources

Original game data is fetched at build time from [OpenSupaplex](https://github.com/sergiou87/open-supaplex) at a pinned commit, never committed here. Format details (planar layout, palette encoding) learned from OpenSupaplex; decoder written from scratch.

Screen fonts

Colour fonts learned from the screens, exact at font sizes of their height ×1, ×2, ×4… px. Only the glyphs seen on screen exist; edit the samples to try them.

Use

@font-face {
  font-family: 'Supaplex 8';
  src: url(supaplex-8.woff2) format('woff2'), url(supaplex-8.ttf) format('truetype');
}
.hud {
  font: 16px/16px 'Supaplex 8';           /* multiples of 8px stay pixel-exact */
  -webkit-font-smoothing: antialiased;   /* macOS: stops glyphs widening */
}
